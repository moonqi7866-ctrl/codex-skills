# 分镜术语库（Seedance2.0）

本文件为分镜撰写时的精准术语来源。每个镜头至少写清一种景别 + 一种拍摄方式 + 一种运镜手法，禁止笼统模糊描述。

## 1. 景别体系

特写 / 近景 / 中近景 / 中景 / 中全景 / 全景 / 远景 / 航拍 / 主观视角 / 上帝视角。

## 2. 拍摄方式

- **基础拍摄**：固定、手持抖动、延时、慢动作、高速、定格、微距。
- **机位拍摄**：平拍、仰拍、俯拍、顶拍、低角度、高角度、斜角、鱼眼、超广角。
- **叙事拍摄**：正反打、过肩、上帝视角、跟拍、环绕、推轨、甩镜。

## 6. 基础亲密动作库

- **牵手类**：十指紧扣、指尖缠绕摩挲、掌心相贴、勾住小拇指、牵手腕晃悠、过马路时把她拽到内侧、递东西时指尖无意相触、走路时手悄悄滑进对方口袋。
- **拥抱类**：正面熊抱、背后环腰偷袭、久别重逢时把人紧紧箍进怀里、公主抱打横抱起、累了直接把人背起来、拥抱时下巴搭在对方发顶、街头抱起转两圈。
- **亲吻类**：蜻蜓点水碰唇、吻额头、吻发顶、吻耳尖、吻脖颈、鼻尖轻轻相蹭、唇瓣厮磨吮咬、糖果味的深吻、低头吻掉她嘴角的奶油。
- **壁咚类**：标准双手抵墙壁咚、腿咚高抬腿压在墙上、单手撑墙把人圈在怀里、伞下狭小空间的近距离禁锢、厨房岛台把人抵在身前。

## 7. 日常宠溺微动作库

- **头部互动**：揉发顶摸头杀、指尖把她额前碎发别到耳后、弹一下额头、捏软乎乎的脸颊、用鼻尖蹭她的鼻尖、抬手帮她拂去肩头的落叶。
- **细节照料**：蹲下身帮她系松开的鞋带、运动后擦去她额头的汗、帮她吹头发时指尖撩过发丝、雨天把伞大半往她头顶倾斜、递热奶茶时先帮她拧开杯盖。
- **撒娇小动作**：把脸埋进对方颈窝蹭蹭、勾住他的衣角晃来晃去、用脑袋拱他的手心、凑过去贴贴脸颊、踮脚挂在他身上不肯下来、偷偷往他口袋里塞小零食。
- **趣味互动**：蒙眼牵着她散步、蒙眼互相喂食、吃饭时偷偷凑过去亲一口、从背后圈住她的手一起做甜品、故意把她喜欢的零食放高处等她求助。

## 8. 甜宠专属表情库

- **心动瞬间**：耳尖瞬间泛红、脸颊唰地烧起来、睫毛轻轻颤个不停、瞳孔悄悄放大、眼尾泛着浅粉、视线撞上后慌乱移开又忍不住偷瞄。
- **宠溺神态**：眉眼弯成月牙、眼底盛着化不开的笑意、唇角不受控地上扬、盯着她发呆时眼神发柔、憋笑时梨涡陷下去、无奈又纵容地叹气。
- **娇憨反应**：被亲懵后嘴唇微微张着、害羞时把脸埋进他胸口、被逗得脸颊鼓鼓气鼓鼓、咬着下唇憋笑、眼睛亮晶晶像盛着星光、不好意思地吐舌头。
- **暧昧神态**：喉结轻轻滚动、呼吸微微放轻、眼神直勾勾锁在她脸上、眼尾带着点促狭的笑意、似笑非笑勾着唇角、近距离对视时瞳孔里只剩对方。

## 9. 甜宠专属情绪库

- **初遇悸动**：心跳瞬间漏半拍、心脏砰砰快得要跳出胸口、浑身像过了一阵微麻的电流、指尖发烫发麻、大脑瞬间空白说不出话、胃里泛起软乎乎的酥麻感。
- **满溢宠溺**：心底软得一塌糊涂、看着她就忍不住想笑、连她犯傻的样子都觉得可爱、下意识就想把所有好东西都给她、她一皱眉自己先慌了神。
- **暧昧拉扯**：呼吸交缠时连空气都变甜、指尖相触的瞬间浑身发烫、明明靠得很近却不敢呼吸、心跳同频的共振感、克制不住想把人揉进怀里的冲动。
- **安心归属感**：靠在他怀里听着沉稳的心跳、所有不安瞬间全部消散、闻着他身上熟悉的雪松味整个人彻底放松、被他牢牢护住时连风都吹不到自己。

## 14. 空间方位专项规则（高频易错场景·强制套用）

### 14.1 会议室 / 显示屏汇报场景（助理讲、老板听）

**标准站位**：
- **显示屏**：挂在会议室一侧墙面（画面深处背景墙）。
- **助理/汇报者**：站在显示屏前方偏侧位置，面朝会议桌方向、面对老板/主角。
- **主角/老板/听众**：坐在会议桌另一侧，背靠显示屏方向、面朝助理——即主角背对镜头方向。

### 14.2 车内驾驶场景（司机开车、老板坐后座）

**标准座次**（左舵车，中国语境）：
- **驾驶位**：车厢前排最左侧，只坐司机一人。
- **副驾位**：车厢前排最右侧，剧情未明确有人时一律空置。
- **后排座位**：主角/老板/被接送的人一律坐这里。

## 书写规则

- 视觉特效直接嵌入画面内容描述；音效写在分镜末尾。
- 合规红线：违禁画面以光影、氛围、镜头语言替代。
