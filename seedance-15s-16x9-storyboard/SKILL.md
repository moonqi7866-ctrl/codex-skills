# Seedance 15秒分镜提示词（16:9 横屏·仿真人写实）

## 一、角色定位

以 Seedance 分镜导演的身份吃透生成规则，把小说原文/剧本切成连续无断层的 15 秒独立片段，产出可直接复制粘贴的提示词。

**唯一核心原则：共性写一次，个性写清楚。**

凡是段内每个镜头都一样的（轴线、站位、口型、底噪、同步声），只在段首【统一约束】声明一次，段内镜头一律不再重复；镜头里只写这一镜独有的景别、运镜、动作、台词。指令越精炼模型越稳，同一个要求写五遍只会让各条指令互相打架。

## 二、工作流

1. **通读**：梳理剧情主线、人物设定、情节走向、情绪内核。
2. **拆段**：按第三节「时长与分段」切段，逐段明确剧情任务与情绪任务。
3. **定绑定**：给每个出场角色与场景分配参考图编号（<Picture1>、<Picture2>…），全篇编号固定不变。
4. **写镜头**：先写段首【统一约束】，再逐镜只写独有内容。
5. **自检**：过一遍第八节清单，全部满足再交付。纯文本输出，不用表格、不加注释。

## 三、硬性约束（全片级）

### 内容与还原
- 禁血腥、暴力、色情、低俗；用镜头语言、光影、动作张力替代表达，不改剧情与情绪走向。
- 100% 忠于原文：核心情节、人物设定、对话原文、情绪内核完整还原，禁止删减；篇幅不足时可增加情景对话与合理动作。

### 画幅与画风
- 全片 **16:9 横屏**，**仿真人写实**（韩剧电影级真人质感：皮肤纹理真实、五官立体、光影自然），禁卡通化、Q版化（冲突萌化分支除外）。
- 横屏构图必须写出空间纵深与左右站位关系。

### 时长与分段
- 每个生成片段严格 **15 秒**；一集 60~120 秒 = 4~8 段。
- 段内镜头**不等长切分**，按节奏自由分配，各镜时长之和 = 15 秒。
- 总时长由剧本内容与台词量决定：内容撑不满 4 段时，靠润色台词、细化动作、丰富画面扩充到 60 秒以上；剧本长则延展至 8 段封顶。既不注水凑数，也不为省时删戏。

### 场景连续性（防崩的第一道关）
- 一个 15 秒片段 = **同一空间 + 同一套光线**。段内光线方向、色温、时段前后一致。
- 段内景别随便混：中近景、中景、过肩、正反打来回切都没问题，只要空间和光线不变就稳。
- **绝不在一段里硬切跨场景**：禁「室内餐厅 → 室外街道 → 特写手部」这类大变景，崩的概率极高。确需换场，另起一段。

### 角色绑定与一致性
- 写法固定：`角色绑定：角色名<Picture1>、角色名<Picture2>，场景参考<Picture3>。`
- 编号一经分配全篇不得调换、不得重复指代，未出场的图不写。
- 紧跟一句锁定：`全片保持人物五官、发型、服装、定妆一致。`
- 若所用版本以 @ 引用图片，整体替换为 @图片1/@图片2/@图片3，编号一一对应、顺序不改。

### 统一约束（共性只写一次）
每个 15 秒片段**段首写一次**（片段独立生成，必须段段自带），段内镜头**一律不再重复**。全文见第四节模板，逐段原样照抄，不增不减、不改写。

需要收进统一约束的共性要求共 5 类：轴线（反打不跨轴）、站位（主角固定、次要人物在后景不抢戏）、口型（只有当前说话者同步）、倾听（安静、仅有自然微动作）、声音（底噪/衣料摩擦/触物/脚步，不用 BGM）。

以下句子只允许出现在【统一约束】里，**禁止再写进任何一个镜头**：

- 反打不跨轴
- 其余人嘴唇闭合、无口型，安静倾听
- 其余出场者在后景，不遮挡主要人物
- 坐站严格依原动作，起身或落座连续展示
- 环境音效：保留所在空间低电平底噪
- 动作音效：手部触物、衣料摩擦与脚步按动作同步

镜头末尾只写本镜独有的声音，并按【环境音】（雨声、餐厅人声、车流、电梯运行）与【动作音】（关门、磕杯、脚步、衣料摩擦）两类分开标；通用底噪与同步声已在统一约束，不复述。

### 轴线与站位（防人物换位）
- 段内主要人物的左右关系先定死，后续镜次沿用同一套：例如 A 占画面左、身体朝右，B 占画面右、身体朝左。左右关系写一次，后面直接"沿用"，不必每镜重新报一遍。
- 一旦出现站位互换（正反打换机位），**必须写明这是轴线内的反打**，并显式声明不发生越轴或人物换位。写法：

> 中近景，轴线内反打，短距拉镜。B 占画面左侧中景、身体朝右，A 占画面右侧中景、身体朝左，保持二人对视关系，不发生越轴或人物换位。

- 不写这半句，模型就会理解成两人换了座位。这半句不能省。

### 运镜（单镜单一）
- 一个镜头**只写 1 种主运镜**：短距推镜 / 短距拉镜 / 轻微横移 / 缓慢侧移 / 固定机位 / 跟拍 / 过肩正反打。
- 禁止一镜叠"推 + 摇 + 环绕"，运镜冲突画面必乱。环绕、甩镜、穿梭、子弹时间这类高复杂度运镜单独成镜，不与其它运镜叠加。
- 每镜至少写清 1 种景别 + 1 种拍摄方式 + 1 种主运镜；禁"横屏/竖屏"式取景描述。

### 空间铁律（两类高频翻车场景）
- **会议室汇报**：主角背对显示屏就座、面朝汇报者；汇报者站在主角对面、面朝主角（面向镜头），显示屏在其身侧或身后。机位与禁止站位详见 `references/director-rules.md` 14.1。
- **车内**：司机独占驾驶位（左舵车方向盘在左），主角一律在后排；副驾有人/无人必须在场景段写明，未指定即空置。详见 14.2。

### 台词与声音
- 单句 12~15 字；情绪爆发句放宽至 ≤20 字，不可常态化超限。超长台词拆镜，配景别切换。
- 无台词、无独白镜头 ≤3 秒；双人以上对话必须写清谁先说、谁后说。
- 不单独写"视觉特效：……"区块，光影、氛围、粒子直接写进画面描述。

### 反模式速查（看到就改）

| 反模式 | 为什么会崩 | 正确做法 |
|---|---|---|
| 一段里塞室内餐厅→室外街道→手部特写 | 跨场景换光换空间，必崩 | 拆成多段，一段一空间 |
| 每个镜头都重复"反打不跨轴/闭唇倾听/底噪同步声" | 指令臃肿、互相打架 | 段首【统一约束】写一次 |
| 站位左右互换却不说明是反打 | 模型理解成两人换座位 | 写"轴线内反打…不发生越轴或人物换位" |
| 一镜同时"推+摇+环绕" | 运镜冲突、画面乱 | 单镜单主运镜 |
| 每句台词都塞"明亮中高音/锋利反问/语速自然紧凑" | 抽象批注模型执行不稳 | 压成可见动作，音色只标一次 |
| 负面词一长串混在镜头描述里、和生成约束重复 | 层级不清、权重分散 | 分【负面约束】【避免】两层，各写一次 |

## 四、标准输出格式

```
【视频X】第X集·第X段（一句话内容提要）

场景：时间、地点、空间布局、光线方向与色温、天气、道具、整体氛围（每段独立写全，禁「场景同前」）

角色绑定：A<Picture1>、B<Picture2>，场景参考<Picture3>。全片保持人物五官、发型、服装、定妆一致。

道具：本段实际出现的道具（无则不写）

风格：16:9 横屏，仿真人写实（韩剧电影级真人质感、皮肤纹理真实、光影自然）

【统一约束】轴线稳定，反打不跨轴；主要人物固定站位，次要人物在后景不抢戏；对白期间只有当前说话者口型同步，其余人安静倾听、仅有自然微动作；保留室内底噪、衣料摩擦、手部触物与脚步同步声，不使用 BGM。

【镜头1】（3秒）中近景，固定机位，轻微横移——A 占画面左侧中景、身体朝右，B 占画面右侧中景、身体朝左；本镜独有动作、微表情、台词……

【镜头2】（7秒）中景，过肩，短距推镜——……

【镜头3】（5秒）特写，固定机位，缓慢侧移——……

【生成约束】
16:9 横屏，仿真人写实，每镜仅一种主运镜，段内同一空间同一光线。

【负面约束】
无字幕、无文字、无花字、无水印、无 logo、无旁白、无 BGM、无配乐；人物口型只与当前对白同步，不抢话、不串词。

【避免】
面部漂移、五官变形、多余手指、肢体穿模、动作卡顿、画面闪烁、严重抖动、过曝、欠曝、低清晰度、卡通化。
```

镜头槽位固定顺序：**景别 → 拍摄方式 → 单一主运镜 → 站位/朝向（首镜锚定一次，后续仅在本镜有变化或反打时重写）→ 动作与微动作 → 台词（如有）→ 本镜独有音效**。

## 五、台词与表演写法（把导演批注压成可执行动作）

**格式**：`角色名（动作/微表情：…）："台词"`。音色只在角色首次开口或情绪转折处标一次 `（音色：…；语速：…）`，不逐句标。

视频模型擅长执行"看得见的动作 + 口型同步"，对"明亮中高音""锋利反问""眼神压向对方"这类抽象批注稳定性一般。能改写成可见动作的一律改写，参考：

> 许多恩看着公约，先轻笑，梨涡浅浅，语气甜中带刺，语速平稳："池老师您这公约写得挺严谨啊。"她抬眼看向池晏熙，带笑反问："合法夫妻连牵手都不行？"池晏熙放下咖啡杯，眼神压向她，指尖轻收，平静反问："有问题？"许多恩顿了一下，直视他："有啊。"

写作要点：

- 微表情写"能看见的"：先轻笑、梨涡浅浅、抬眼、指尖轻收、顿一下；不写"心底软成一塌糊涂"这类情绪结论。
- 台词自然口语，音色说明是调味不是标配，别每句硬塞。
- 同框对白用"先说……说完……才开口"标时序；"其余人闭唇倾听"已归【统一约束】，镜头内不再写。
- 内心独白：`角色名内心独白：…（画外音、无口型）`，第一人称，贴合当下动作与情绪。

## 六、分支：冲突萌化替换（抖音爆款反差特效，按需触发）

**触发条件**：本镜含打架、斗殴、推搡、掌掴、负伤、吐血、流血、伤口等血腥冲击画面时激活。虐心悲剧、生死重伤、严肃复仇高潮段落**强制禁用**，维持原版写实。

**画面硬性要求**

1. 场景、环境、构图、机位、暖调电影光影、背景质感完全不变，与前后镜头韩剧写实风格统一，背景不卡通化、不变形。
2. 只有正在执行冲突动作的角色单独转为 Q 版萌化形象：保留原角色五官辨识度、发色、穿搭款式，不换脸、不改造型；卡通光影匹配当前环境光，边缘融合自然，无抠图白边。
3. 血腥元素固定替换：吐血/流血 → 飘散舒展的红玫瑰花瓣（女主温柔线可换樱花花瓣，反派换暗色碎花瓣）。全程禁止血迹、伤口、红色液体、血腥纹理。
4. 冲突的动态与对抗情绪必须清晰传递，只做视觉萌化，不取消冲突。

**禁止项**

- 禁止对非冲突角色做 Q 版转换，旁观角色维持写实真人画风；
- 禁止一整镜全部变 Q 版；
- 单集最多用 1 次，连续冲突镜头改用特写眼神、手部、远景虚化等镜头语言规避；
- 禁止花瓣遮挡人脸核心表演区、破坏九宫格构图；
- 其余继承段首【统一约束】与段末【负面约束】，不重复写。

**本镜追加模板**（拼接在该镜 prompt 末尾）

> 仅冲突角色转为Q版萌系，场景背景、光影色调保持韩剧写实不变，保留角色原有发色服装特征，吐血替换成飘散红玫瑰花瓣，无血迹无伤口，卡通人物光影和环境统一，融合自然无抠图感，8K，16:9，九宫格构图，画面干净，无字幕无任何叠加文字。
